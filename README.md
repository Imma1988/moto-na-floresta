# Moto na Floresta

Jogo de moto para correr no browser, feito para uma crianca de 6 anos.

## Como jogar

- Abre `index.html` no browser.
- Usa as setas ou `A` / `D` para virar.
- Usa `Espaco` para saltar.
- Desvia de troncos e pedras.
- Apanha estrelas para ganhar mais pontos.

## Ficheiros

- `index.html`: estrutura do jogo.
- `styles.css`: interface e apresentacao.
- `game.js`: desenho, fisica simples, pontuacao e controlos.
